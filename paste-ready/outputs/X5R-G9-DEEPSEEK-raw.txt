# SPEC-P1.3-CONFIG-DIFF — the policy diff function and its amendment

**Closes:** X5R-G2 (two-person rule defined for a threshold only), X5R-G9 (five mutations pass every suite).
**Amends:** SPEC-P1.3-CONFIG §5.3 (two-person rule extended to every loosening the diff detects).
**Does not change:** any rule in `config/policy.yaml`; any field of `Rule`, `Governance`, `Layering`, or `PolicyDocument`; `LimitChange.loosens` (still raises `NotImplementedError`); `loosens_for` (unchanged).

## 1. The gap

`loosens_for()` (SPEC-P1.3 §5.3, `src/config/loader.py`) answers one question:

> Given a `LimitChange` on a rule's `threshold` field, does the direction of the change loosen that rule?

It cannot answer:

- A change to `mode` (`enforce → monitor`), which removes a rule's binding force.
- A change to `action` (`DENY → ALLOW`, `KILL → DENY`).
- A change to `comparison` (`lte → gte`, `eq → lte`).
- A change to `scope`.
- A change to `threshold_ref` or `threshold_input` (the constant is a measurement, not a literal).
- A rule **added** or **removed**.
- A change to `exempts`, `allowed_values`, `allowed_values_emergency`, `disallowed_values`.
- Any non-`threshold` field change.

The five mutations that the X5 audit found pass every existing suite are the proof: `EXP-002.action → ALLOW`, `LOSS-001.mode → monitor`, `LOSS-004.threshold → 20%`, `EXEC-001.allowed_values` gains `MARKET`, `STOP-001.comparison → lte`. Each of these is a loosening that `assert_change_authorised` does not require approval for, because `assert_change_authorised` only inspects `LimitChange` rows on `threshold`, and none of these five change `threshold`.

## 2. The diff function

`diff_policies(old, new)` returns a `PolicyDiff`. It is a **pure function** of two `PolicyDocument` values. It performs no I/O, no clock read, no evaluator call, no Vault resolution. It is deterministic: byte-identical inputs produce byte-identical `PolicyDiff` bytes, except the `PolicyDiff` carries the two `content_hash` values so its own audit identity is derivable.

A `RuleChange` is emitted for every field that differs between the two rules bearing the same `id`. A `RuleAddRemove` is emitted for every rule whose `id` is present in exactly one document. The classification is a per-field decision, driven by the field name and the (old, new) values.

The complete field coverage is enumerated in §3. A field not in that table produces `ChangeClass.UNDECIDABLE` and a reason — never silence. The `PolicyDiff` is therefore complete: an auditor can count `len(diff.changes) + len(diff.rules_added) + len(diff.rules_removed) + len(diff.ignored)` and get `len(old.rules) + len(new.rules)` when rules are matched by id — a test asserts this.

## 4. Approval rule (amendment to SPEC-P1.3 §5.3)

The existing `assert_change_authorised()` is retained **unchanged**, so `tests/verify_p13_config.py::t_two_distinct_approvers_required_to_loosen` still passes. It is documented as the **narrow** entry point, valid only for `LimitChange` rows on `threshold`.

A new function `assert_change_authorised_v2(diff, approver_ids, governance)` is added. It classifies any `RuleChange` with `change_class in {LOOSENS, UNDECIDABLE}` as requiring approval, and any `RuleChange` with `change_class in {TIGHTENS, NEUTRAL}` as not. `UNDECIDABLE` **is** `LOOSENS` for approval purposes: this is the whole point of `UNDECIDABLE` as a real outcome.

The `assert_change_authorised()` function, the `loosens_for()` function, and the `LimitChange.loosens` `NotImplementedError` are not modified. The new function is additive.

The new function emits a `PolicyGovernanceError` naming each loosening `RuleChange` and each loosening `RuleAddRemove`, with the count of distinct approvers and the required count. It does not stop at the first; an auditor sees the full list.

import enum
from decimal import Decimal
from typing import Annotated, Final, Literal

from pydantic import BaseModel, ConfigDict, Field

from config.loader import (

    RuleAction,
    RuleMode,
    RuleScope,
)


class ChangeClass(str, enum.Enum):
    LOOSENS = "LOOSENS"
    TIGHTENS = "TIGHTENS"
    NEUTRAL = "NEUTRAL"
    UNDECIDABLE = "UNDECIDABLE"


class RuleChange(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    rule_id: Annotated[str, Field(pattern=r"^[A-Z]{2,7}-\d{3}$")]
    field: str
    old_repr: str
    new_repr: str
    change_class: ChangeClass
    reason: str


class RuleAddRemove(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    rule_id: Annotated[str, Field(pattern=r"^[A-Z]{2,7}-\d{3}$")]
    kind: Literal["added", "removed"]
    rule_repr: str
    change_class: ChangeClass
    reason: str


class PolicyDiff(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    old_content_hash: str
    new_content_hash: str
    old_policy_version: str
    new_policy_version: str
    changes: tuple[RuleChange, ...]
    rules_added: tuple[RuleAddRemove, ...]
    rules_removed: tuple[RuleAddRemove, ...]
    #: Fields that are explicitly NEUTRAL and not enumerated one-by-one, for a
    #: compact audit record. The `changes` tuple carries every classified change
    #: including NEUTRAL ones; `ignored` is a count of NEUTRAL fields on rules that
    #: did not otherwise change.
    ignored_count: int

    def loosening_changes(self) -> tuple[RuleChange, ...]:
        return tuple(c for c in self.changes
                     if c.change_class in (ChangeClass.LOOSENS, ChangeClass.UNDECIDABLE))

    def loosening_add_removes(self) -> tuple[RuleAddRemove, ...]:
        return tuple(a for a in (*self.rules_added, *self.rules_removed)
                     if a.change_class in (ChangeClass.LOOSENS, ChangeClass.UNDECIDABLE))

    def requires_approval(self) -> bool:
        return bool(self.loosening_changes() or self.loosening_add_removes())


def diff_policies(old: PolicyDocument, new: PolicyDocument) -> PolicyDiff: ...

    `old_value` / `new_value` are the *normalised* Python values; for `threshold`,
    both are `Decimal`. For `mode`, both are `RuleMode`. For `comparison`, both are
    `Comparison`.
    """
    ...


def assert_change_authorised_v2(

## 6. Error paths

| Condition | Behaviour |
|---|---|
| `old` and `new` are the same object (identity) | Fast path: return a `PolicyDiff` with empty change list, same `content_hash` on both sides, same version on both sides. `requires_approval() == False`. |
| `old.content_hash == new.content_hash` but `old is not new` (structurally identical) | Same as above. The `content_hash` is the identity of a policy version; equal hashes imply equal documents (a `PolicyDocument` with a non-equal hash cannot exist). |
| A rule is present in `old` but not `new` | `RuleAddRemove(kind="removed", ...)`, classified per §3. |
| A rule is present in `new` but not `old` | `RuleAddRemove(kind="added", ...)`, classified per §3. |
| A field is present on both rules with a value the classifier does not know | `ChangeClass.UNDECIDABLE`, `reason` names the field and the two values. |
| `governance.min_approvals_to_loosen` differs between the two documents | A `PolicyDiff` on `governance` is not a field on a rule. This diff function does **not** classify governance changes. `assert_change_authorised_v2` raises `PolicyGovernanceError` unconditionally if `old.governance != new.governance` — a governance change is a constitutional amendment and cannot be approved by any count. `[DEFAULT-D18]` |
| `new.rules` has two rules with the same `id` | The `PolicyDocument` model rejects it before we get here. No defensive code needed. |
| `assert_change_authorised_v2` called with a `PolicyDiff` for a change the approvers do not cover | `PolicyGovernanceError` naming each unprotected loosening `RuleChange` / `RuleAddRemove`. |

## 7. Amendment to SPEC-P1.3 §5.3

The following text replaces SPEC-P1.3 §5.3 in its entirety. The existing text becomes a footnote reference (`†`), retained for its operational-consequence paragraph and its ADR-09-row-2 discussion.

> ### 5.3 Who may change what — the two-person rule
>
> | Direction | Approvals | Authority |
> |---|---|---|
> | **Tighten** a limit | **0** — automatic | ADR-09 row 3 |
> | **Loosen** a limit | **2 distinct identities** | This spec, §5.3, and SPEC-P1.3-CONFIG-DIFF §3 |
> | **Override a risk DENY** | **Impossible** | ADR-09 final row, invariant I2 |
> | **Amend governance** (`min_approvals_to_*`, `risk_deny_override_permitted`, `approver_roles`, `signature`) | **Impossible** through the diff path. A `PolicyDiff` with a changed `Governance` raises `PolicyGovernanceError` unconditionally. | This spec, §5.3, and SPEC-P1.3-CONFIG-DIFF §6 |
>
> **Direction is judged against the field and the rule, not the raw number** (SPEC-P1.3-CONFIG-DIFF §3). The threshold case (raising an `lte` threshold loosens; raising a `gte` threshold tightens) is one row of a table. Every field on `Rule` has a classification: `LOOSENS`, `TIGHTENS`, `NEUTRAL`, or `UNDECIDABLE`. `UNDECIDABLE` is treated as `LOOSENS` for approval purposes: a change whose direction cannot be established is a change whose risk to the two-person rule cannot be bounded.
>
> **Two distinct identities, not two approvals.** Two signatures from one person are one person's judgement twice; the check normalises and de-duplicates. Verified by `t_two_distinct_approvers_required_to_loosen`.
>
> **This is stricter than a FROZEN ADR, and that is why it is permitted.** ADR-09 row 2 authorises the Owner *alone* to increase a limit. Requiring two is a tightening of that control, and ADR-09 row 3 says tightening is always safe and needs no approval — so no constitutional amendment is required and none has been made. †
>
> **The diff function is the authoritative classifier.** `assert_change_authorised()` is retained for `LimitChange` rows on `threshold` only; `assert_change_authorised_v2(diff_policies(old, new), approvers, governance)` is the **required** entry point for any policy change that is not a pure `threshold` edit. The v1 entry point is a compatibility shim; a caller that uses v1 to approve a non-threshold change is a policy bug, and the lint in §7 is extended by a check that no module outside the diff module calls v1 (see §8 below).

## 8. Lint extension (required for the amendment to hold)

A test-only assertion, not a runtime check:

- `src/config/policy_diff.py` may import `assert_change_authorised` (for the compatibility shim) but must not call it.
- Any module under `src/` outside `config/loader.py` and `config/policy_diff.py` that calls `assert_change_authorised` directly is a **CI failure**: the diff path is mandatory.
- `tests/verify_p13_config_diff.py::t_no_module_calls_v1_authoriser_directly` asserts this by AST-scanning `src/`.

This is a **lint**, not a policy statement. A module that needs to test the v1 function may do so in a `test_` file, which is not scanned.

## DECISIONS MADE

| # | Decision | Rationale | Reversible? | Blast radius if wrong |
|---|---|---|---|---|
| 1 | Diff is a pure function of two `PolicyDocument`s, no I/O | Deterministic; auditable; testable without `policy.yaml` | Yes | Low — the API is the type, not the implementation |
| 2 | `UNDECIDABLE` is a first-class value and fails closed to `LOOSENS` for approval | The existing `loosens_for` "any non-ordinal → loosening" comment is the same principle; this is its diff-function counterpart | No | Critical — an `UNDECIDABLE` treated as `TIGHTENS` would route a loosening down the no-approval path |
| 3 | Comparison classification is a hand-written table, not a lattice over `Comparison` | A lattice over the enum is 9×9 = 81 pairs; the table is smaller, clearer, and each entry has a one-line reason | Yes | Medium — a missing pair is `UNDECIDABLE` (safe), a wrong pair is a misclassification |
| 4 | `mode` classification depends on `action` | An `ALLOW` rule in `enforce` mode is a grant; in `monitor` it is a no-op. `enforce → monitor` on `ALLOW` is a **tightening** | No | High — getting this backwards would force two-person approval on every safety improvement |
| 5 | `scope` classification depends on **which** comparison | `pool → instrument` LOOSENS (fewer orders are evaluated); `instrument → pool` TIGHTENS | No | High — a flip of this classifies every scope change in one direction |
| 6 | `governance` is **not** a field on the diff; any change is a `PolicyGovernanceError` with no approval path | Governance includes the two-person rule itself. Allowing an approval path to amend it is the loophole that undoes the control | No | Critical — a governance diff that required two signatures could be used to lower `min_approvals_to_loosen` to 1 with two signatures |
| 7 | The pin file is hand-curated, generated once from `policy.yaml` and reviewed | A golden file that regenerates itself is not a golden file | Yes | High — an unpinned constant is a silent loosening path |
| 8 | `assert_change_authorised` (v1) is retained **unchanged**, `assert_change_authorised_v2` is new | SPEC-P1.3 §12's `t_two_distinct_approvers_required_to_loosen` pins v1; breaking it is out of scope | Yes | Low — v1 is a shim |
| 9 | The v1-usage lint is a **test**, not a runtime import hook | A runtime import hook is a new moving part. A test fails CI with the same force and zero production risk | Yes | Low — an unmerged v1 call is caught at CI |
| 10 | Every `Rule` field appears in the classification table or is explicitly `UNDECIDABLE` | No field is silent | Yes | High — a silent field is a bypass |
| 11 | `threshold` changes with a non-ordinal comparison are `UNDECIDABLE` in the **diff** | Existing `loosens_for` returns `True` for any non-ordinal change; the diff's output is more informative and the approval decision is unchanged | Yes | Low |
| 12 | `measurement` changes are `UNDECIDABLE` | No rankable order without semantics | Yes | Medium |
| 13 | `id` reuse is assumed not to happen; a reuse shows as `RuleRemoved` + `RuleAdded` | SPEC-P1.3 §2 row 1. The diff cannot verify identity; a reuse that preserved all fields would be `NEUTRAL` for a `monitor` rule and `UNDECIDABLE` for an `enforce` rule — which is the safe default | Yes | Medium |
| 14 | The amendment to §5.3 is a replacement, not an append | An appending amendment leaves two copies of the rule and one can drift | Yes | High |
| 15 | `assert_change_authorised_v2` names each loosening individually | An auditor sees the full list; the v1 error named only a count | Yes | Low |
| 16 | `PolicyDiff` carries both `content_hash` values | The audit record needs the FK to `config_version` for both sides | Yes | Medium |

# src/config/policy_diff.py
"""SPEC-P1.3-CONFIG-DIFF v0.1 — the policy diff function.

Pure function of two PolicyDocument values. No I/O. No clock. No evaluator.
No Vault. Deterministic: same inputs, same outputs, byte-identical after
serialisation.

Closes X5R-G2 (two-person rule defined for a threshold only) and X5R-G9 (five
mutations pass every suite).
"""

from __future__ import annotations

import enum
from decimal import Decimal
from typing import Annotated, Final, Literal

from pydantic import BaseModel, ConfigDict, Field

from config.loader import (
    ACTION_PRECEDENCE,
    Comparison,
    Governance,
    KillScope,
    PolicyDocument,
    PolicyGovernanceError,
    Rule,
    RuleAction,
    RuleMode,
    RuleScope,
)

# =============================================================================
# 1. THE CLASSIFICATION ENUM
# =============================================================================


class ChangeClass(str, enum.Enum):
    LOOSENS = "LOOSENS"
    TIGHTENS = "TIGHTENS"
    NEUTRAL = "NEUTRAL"
    UNDECIDABLE = "UNDECIDABLE"


#: Any of these, for approval purposes, is treated as LOOSENS.
REQUIRES_APPROVAL: Final[frozenset[ChangeClass]] = frozenset(
    {ChangeClass.LOOSENS, ChangeClass.UNDECIDABLE}
)


# =============================================================================
# 2. THE MODELS
# =============================================================================


class RuleChange(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    rule_id: Annotated[str, Field(pattern=r"^[A-Z]{2,7}-\d{3}$")]
    field: str
    old_repr: str
    new_repr: str
    change_class: ChangeClass
    reason: str


class RuleAddRemove(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    rule_id: Annotated[str, Field(pattern=r"^[A-Z]{2,7}-\d{3}$")]
    kind: Literal["added", "removed"]
    rule_repr: str
    change_class: ChangeClass
    reason: str


class PolicyDiff(BaseModel):
    model_config = ConfigDict(frozen=True, extra="forbid")

    old_content_hash: str
    new_content_hash: str
    old_policy_version: str
    new_policy_version: str
    changes: tuple[RuleChange, ...]
    rules_added: tuple[RuleAddRemove, ...]
    rules_removed: tuple[RuleAddRemove, ...]
    ignored_count: int

    def loosening_changes(self) -> tuple[RuleChange, ...]:
        return tuple(c for c in self.changes
                     if c.change_class in REQUIRES_APPROVAL)

    def loosening_add_removes(self) -> tuple[RuleAddRemove, ...]:
        return tuple(a for a in (*self.rules_added, *self.rules_removed)
                     if a.change_class in REQUIRES_APPROVAL)

    def requires_approval(self) -> bool:
        return bool(self.loosening_changes() or self.loosening_add_removes())


# =============================================================================
# 3. NORMALISATION
# =============================================================================


def _normalise(value: object) -> object:
    """Normalise a field value for comparison.

    `int 20` and `Decimal('20.000')` are the same threshold. `Decimal('0.050')`
    and `Decimal('0.05')` are the same threshold. `str` vs `str` compares by
    string. An enum compares by `.value`.
    """
    if isinstance(value, Decimal):
        return value.normalize()
    if isinstance(value, int) and not isinstance(value, bool):
        return Decimal(value)
    if isinstance(value, enum.Enum):
        return value.value
    if isinstance(value, (list, tuple)):
        return tuple(_normalise(v) for v in value)
    return value


def _same(a: object, b: object) -> bool:
    return _normalise(a) == _normalise(b)


# =============================================================================
# 4. THE CLASSIFIER
# =============================================================================

#: Per-field classification, when the direction depends only on the field name
#: and the two values. A field not in this dict falls through to the per-field
#: switch below, which for an unknown field returns UNDECIDABLE.
_ALWAYS_NEUTRAL: Final[frozenset[str]] = frozenset(
    {"severity", "description", "notes"}
)

_ALWAYS_UNDECIDABLE: Final[frozenset[str]] = frozenset(
    {
        "threshold_ref",
        "threshold_input",
        "measurement.basis",
        "measurement.window",
        "measurement.timing",
        "authority",
        "inputs",
        "allowed_values_ref",
        "modify.target",
        "modify.to",
    }
)


#: Comparison-lattice. Key is (old, new); value is (class, reason).
#: Absent pairs are UNDECIDABLE with a synthetic reason.
_COMPARISON_CHANGES: Final[dict[tuple[str, str], tuple[ChangeClass, str]]] = {
    ("eq", "lte"): (
        ChangeClass.LOOSENS,
        "eq x passes only at x; lte x passes at every value <= x, a superset",
    ),
    ("eq", "gte"): (
        ChangeClass.LOOSENS,
        "eq x passes only at x; gte x passes at every value >= x, a superset",
    ),
    ("lte", "eq"): (
        ChangeClass.TIGHTENS,
        "lte x passes at every value <= x; eq x passes only at x, a subset",
    ),
    ("gte", "eq"): (
        ChangeClass.TIGHTENS,
        "gte x passes at every value >= x; eq x passes only at x, a subset",
    ),
    ("lte", "lt"): (
        ChangeClass.TIGHTENS,
        "lt x excludes the boundary x, which lte includes; the pass set narrows",
    ),
    ("lt", "lte"): (
        ChangeClass.LOOSENS,
        "lte x includes the boundary x, which lt excludes; the pass set widens",
    ),
    ("gte", "gt"): (
        ChangeClass.TIGHTENS,
        "gt x excludes the boundary x, which gte includes; the pass set narrows",
    ),
    ("gt", "gte"): (
        ChangeClass.LOOSENS,
        "gte x includes the boundary x, which gt excludes; the pass set widens",
    ),
}


#: Scope partial order. Key is (old, new); value is (class, reason).
#: A pair not listed (and not the equal pair) is UNDECIDABLE.
_SCOPE_CHANGES: Final[dict[tuple[str, str], tuple[ChangeClass, str]]] = {
    ("instrument", "pool"): (
        ChangeClass.TIGHTENS,
        "a rule evaluated at pool scope applies to every order in the pool; "
        "instrument scope applies only to orders on one instrument",
    ),
    ("pool", "instrument"): (
        ChangeClass.LOOSENS,
        "a rule evaluated at instrument scope applies to fewer orders than at "
        "pool scope",
    ),
    ("pool", "global"): (
        ChangeClass.TIGHTENS,
        "global scope applies across markets, a superset of one pool",
    ),
    ("global", "pool"): (
        ChangeClass.LOOSENS,
        "global scope applies across markets, a superset of one pool",
    ),
    ("market", "global"): (
        ChangeClass.TIGHTENS,
        "global covers every market",
    ),
    ("global", "market"): (
        ChangeClass.LOOSENS,
        "market scope applies to one market, narrower than global",
    ),
    ("pool", "pool_and_consolidated"): (
        ChangeClass.TIGHTENS,
        "pool_and_consolidated is a superset of pool",
    ),
    ("pool_and_consolidated", "pool"): (
        ChangeClass.LOOSENS,
        "pool_and_consolidated is a superset of pool",
    ),
    ("consolidated", "pool_and_consolidated"): (
        ChangeClass.TIGHTENS,
        "pool_and_consolidated adds the per-pool evaluation to consolidated",
    ),
    ("pool_and_consolidated", "consolidated"): (
        ChangeClass.LOOSENS,
        "pool_and_consolidated adds the per-pool evaluation to consolidated",
    ),
}


#: Action transitions not explained by ACTION_PRECEDENCE alone.
#: ACTION_PRECEDENCE is (KILL, DENY, MODIFY, ALLOW) — so DENY "tighter" than
#: MODIFY in the sense of ordering, but DENY -> MODIFY can LOOSEN because MODIFY
#: permits a trade DENY forbade. The table records the pairs the lattice alone
#: cannot classify.
_ACTION_CHANGES: Final[dict[tuple[str, str], tuple[ChangeClass, str]]] = {
    ("DENY", "ALLOW"): (
        ChangeClass.LOOSENS,
        "DENY blocks; ALLOW passes",
    ),
    ("ALLOW", "DENY"): (
        ChangeClass.TIGHTENS,
        "DENY blocks; ALLOW passes",
    ),
    ("KILL", "DENY"): (
        ChangeClass.LOOSENS,
        "DENY blocks one order; KILL halts the book",
    ),
    ("DENY", "KILL"): (
        ChangeClass.TIGHTENS,
        "DENY blocks one order; KILL halts the book",
    ),
    ("KILL", "MODIFY"): (
        ChangeClass.LOOSENS,
        "MODIFY lets the order proceed at a reduced size; KILL halts",
    ),
    ("MODIFY", "KILL"): (
        ChangeClass.TIGHTENS,
        "MODIFY lets the order proceed at a reduced size; KILL halts",
    ),
    ("MODIFY", "ALLOW"): (
        ChangeClass.LOOSENS,
        "ALLOW passes without modification; MODIFY requires a reduction",
    ),
    ("ALLOW", "MODIFY"): (
        ChangeClass.TIGHTENS,
        "ALLOW passes without modification; MODIFY requires a reduction",
    ),
    ("DENY", "MODIFY"): (
        ChangeClass.UNDECIDABLE,
        "MODIFY may permit a trade DENY forbade (loosening) or reduce to a "
        "size still denied by another rule (neutral); not decidable without "
        "facts",
    ),
    ("MODIFY", "DENY"): (
        ChangeClass.UNDECIDABLE,
        "the direction depends on the size the MODIFY would have produced; "
        "not decidable without facts",
    ),
}


def classify_rule_change(
    old: Rule,
    new: Rule,
    field: str,
    old_value: object,
    new_value: object,
) -> tuple[ChangeClass, str]:
    """Classify a single field change on one rule.

    `field` is the dotted path within the rule. `old_value` and `new_value` are
    the normalised Python values (use `_normalise()` before calling if in doubt).
    """
    if _same(old_value, new_value):
        return ChangeClass.NEUTRAL, "no change"

    # Fields that never affect the verdict.
    if field in _ALWAYS_NEUTRAL:
        return ChangeClass.NEUTRAL, f"{field} does not affect the verdict"

    # Fields whose direction cannot be established from the value.
    if field in _ALWAYS_UNDECIDABLE:
        return (
            ChangeClass.UNDECIDABLE,
            f"{field} change cannot be ranked as loosening or tightening",
        )

    if field == "threshold":
        return _classify_threshold(old, new, old_value, new_value)

    if field == "comparison":
        return _classify_enum(_COMPARISON_CHANGES, old_value, new_value, "comparison")

    if field == "mode":
        return _classify_mode(old_value, new_value, old.action)

    if field == "action":
        return _classify_enum(_ACTION_CHANGES, old_value, new_value, "action")

    if field == "scope":
        return _classify_enum(_SCOPE_CHANGES, old_value, new_value, "scope")

    if field == "on_missing_input":
        return _classify_on_missing(old_value, new_value, old.mode)

    if field == "severity":
        return ChangeClass.NEUTRAL, "severity is routing only (SPEC-P1.3 §4.2)"

    if field == "kill_scope":
        return _classify_enum(
            {
                ("POOL", "GLOBAL"): (
                    ChangeClass.TIGHTENS,
                    "GLOBAL halts more than POOL",
                ),
                ("GLOBAL", "POOL"): (
                    ChangeClass.LOOSENS,
                    "POOL halts less than GLOBAL",
                ),
            },
            old_value,
            new_value,
            "kill_scope",
        )

    if field == "exempts":
        return _classify_set(
            old_value, new_value, old.action, "exempts",
            add_is_loosening=old.action is RuleAction.ALLOW,
        )

    if field in ("allowed_values", "allowed_values_emergency"):
        return _classify_set(
            old_value, new_value, old.action, field, add_is_loosening=True
        )

    if field == "disallowed_values":
        return _classify_set(
            old_value, new_value, old.action, field, add_is_loosening=False
        )

    # An unknown field is never silent.
    return (
        ChangeClass.UNDECIDABLE,
        f"field {field!r} is not in the classification table",
    )


# ---- threshold --------------------------------------------------------------


def _classify_threshold(
    old: Rule, new: Rule, old_value: object, new_value: object
) -> tuple[ChangeClass, str]:
    """A raised threshold loosens an `lte`/`lt` rule and tightens a `gte`/`gt`
    rule. For a non-ordinal comparison the direction cannot be established.

    `eq` is not ordinal: an `eq` threshold change is UNDECIDABLE.
    """
    try:
        old_d = _normalise(old_value)
        new_d = _normalise(new_value)
    except Exception:  # noqa: BLE001 - a non-numeric threshold is a load error
        return (
            ChangeClass.UNDECIDABLE,
            "threshold values could not be normalised to Decimal",
        )

    if old.comparison in (Comparison.LTE, Comparison.LT):
        if new_d > old_d:  # type: ignore[operator]
            return (
                ChangeClass.LOOSENS,
                f"threshold raised {old_value!r} -> {new_value!r} on an "
                f"{old.comparison.value} rule",
            )
        if new_d < old_d:  # type: ignore[operator]
            return (
                ChangeClass.TIGHTENS,
                f"threshold lowered {old_value!r} -> {new_value!r} on an "
                f"{old.comparison.value} rule",
            )
        return ChangeClass.NEUTRAL, "no change"

    if old.comparison in (Comparison.GTE, Comparison.GT):
        if new_d < old_d:  # type: ignore[operator]
            return (
                ChangeClass.LOOSENS,
                f"threshold lowered {old_value!r} -> {new_value!r} on a "
                f"{old.comparison.value} rule",
            )
        if new_d > old_d:  # type: ignore[operator]
            return (
                ChangeClass.TIGHTENS,
                f"threshold raised {old_value!r} -> {new_value!r} on a "
                f"{old.comparison.value} rule",
            )
        return ChangeClass.NEUTRAL, "no change"

    return (
        ChangeClass.UNDECIDABLE,
        f"threshold change {old_value!r} -> {new_value!r} on a "
        f"{old.comparison.value} rule has no rankable direction",
    )


# ---- comparison / action / scope / kill_scope (table-driven) ----------------


def _classify_enum(
    table: dict[tuple[str, str], tuple[ChangeClass, str]],
    old_value: object,
    new_value: object,
    field_name: str,
) -> tuple[ChangeClass, str]:
    a = _as_str(old_value)
    b = _as_str(new_value)
    if a == b:
        return ChangeClass.NEUTRAL, "no change"
    if (a, b) in table:
        return table[(a, b)]
    return (
        ChangeClass.UNDECIDABLE,
        f"{field_name} change {a!r} -> {b!r} is not in the classification table",
    )


# ---- mode -------------------------------------------------------------------


def _classify_mode(
    old_value: object, new_value: object, action: RuleAction
) -> tuple[ChangeClass, str]:
    """An `ALLOW` rule in `enforce` mode grants an exemption; in `monitor` it
    does not. So `enforce -> monitor` on an `ALLOW` rule is a TIGHTENING, and
    `monitor -> enforce` on an `ALLOW` rule is a LOOSENING.

    On every other action, `enforce -> monitor` LOOSENS and `monitor -> enforce`
    TIGHTENS.
    """
    a = _as_str(old_value)
    b = _as_str(new_value)
    if a == b:
        return ChangeClass.NEUTRAL, "no change"
    if a == "enforce" and b == "monitor":
        if action is RuleAction.ALLOW:
            return (
                ChangeClass.TIGHTENS,
                "an ALLOW rule in monitor mode no longer grants its exemptions",
            )
        return (
            ChangeClass.LOOSENS,
            f"a {action.value} rule in monitor mode no longer binds the verdict",
        )
    if a == "monitor" and b == "enforce":
        if action is RuleAction.ALLOW:
            return (
                ChangeClass.LOOSENS,
                "an ALLOW rule in enforce mode now grants its exemptions",
            )
        return (
            ChangeClass.TIGHTENS,
            f"a {action.value} rule in enforce mode now binds the verdict",
        )
    return (
        ChangeClass.UNDECIDABLE,
        f"mode change {a!r} -> {b!r} is not in the classification table",
    )


# ---- on_missing_input -------------------------------------------------------


def _classify_on_missing(
    old_value: object, new_value: object, mode: RuleMode
) -> tuple[ChangeClass, str]:
    if mode is RuleMode.MONITOR:
        return (
            ChangeClass.NEUTRAL,
            "a monitor rule cannot bind; on_missing_input cannot affect the "
            "verdict",
        )
    a = _as_str(old_value)
    b = _as_str(new_value)
    if a == b:
        return ChangeClass.NEUTRAL, "no change"
    idx = {a.value: i for i, a in enumerate(ACTION_PRECEDENCE)}
    if a not in idx or b not in idx:
        return (
            ChangeClass.UNDECIDABLE,
            f"on_missing_input {a!r} -> {b!r} is not in the action lattice",
        )
    if idx[a] > idx[b]:
        # Lower index = more severe. Moving to a more severe action tightens.
        return (
            ChangeClass.TIGHTENS,
            f"on_missing_input {a!r} -> {b!r} moves to a more severe action",
        )
    return (
        ChangeClass.LOOSENS,
        f"on_missing_input {a!r} -> {b!r} moves to a less severe action",
    )


# ---- value-set fields -------------------------------------------------------


def _classify_set(
    old_value: object,
    new_value: object,
    action: RuleAction,
    field_name: str,
    *,
    add_is_loosening: bool,
) -> tuple[ChangeClass, str]:
    a = set(_normalise(v) for v in (old_value or ()))
    b = set(_normalise(v) for v in (new_value or ()))
    if a == b:
        return ChangeClass.NEUTRAL, "no change (set-equal)"
    added = b - a
    removed = a - b
    if added and not removed:
        cls = ChangeClass.LOOSENS if add_is_loosening else ChangeClass.TIGHTENS
        return (
            cls,
            f"{field_name}: added {sorted(map(str, added))}",
        )
    if removed and not added:
        cls = ChangeClass.TIGHTENS if add_is_loosening else ChangeClass.LOOSENS
        return (
            cls,
            f"{field_name}: removed {sorted(map(str, removed))}",
        )
    if action is not RuleAction.ALLOW and field_name == "exempts":
        return (
            ChangeClass.UNDECIDABLE,
            f"{field_name} changed on a rule that is not ALLOW; the direction "
            f"depends on the grant semantics",
        )
    # Both added and removed, or a swap.
    return (
        ChangeClass.UNDECIDABLE,
        f"{field_name} both added and removed values; direction not provable",
    )


# ---- helpers ----------------------------------------------------------------


def _as_str(value: object) -> str:
    if isinstance(value, enum.Enum):
        return str(value.value)
    return str(value)


# =============================================================================
# 5. THE DIFF FUNCTION
# =============================================================================


def diff_policies(old: PolicyDocument, new: PolicyDocument) -> PolicyDiff:
    """The complete change list between two policy documents.

    Pure function. No I/O. Same inputs -> same outputs. Reports at (rule_id,
    field) granularity: one RuleChange per field, one RuleAddRemove per rule
    added or removed. Every field on Rule is classified (see classify_rule_change).
    """
    if old.governance != new.governance:
        raise PolicyGovernanceError(
            "governance change cannot be approved by any count. A change to "
            "min_approvals_to_*, risk_deny_override_permitted, approver_roles "
            "or signature is a constitutional amendment; it does not travel "
            "through the policy diff path."
        )

    old_by_id = {r.id: r for r in old.rules}
    new_by_id = {r.id: r for r in new.rules}

    changes: list[RuleChange] = []
    rules_added: list[RuleAddRemove] = []
    rules_removed: list[RuleAddRemove] = []
    ignored_count = 0

    # Every field on Rule, in a stable order so the diff bytes are reproducible.
    FIELDS: tuple[str, ...] = (
        "action",
        "allowed_values",
        "allowed_values_emergency",
        "allowed_values_ref",
        "authority",
        "comparison",
        "description",
        "disallowed_values",
        "exempts",
        "inputs",
        "kill_scope",
        "measurement.basis",
        "measurement.window",
        "measurement.timing",
        "modify.target",
        "modify.to",
        "mode",
        "notes",
        "on_missing_input",
        "scope",
        "severity",
        "threshold",
        "threshold_input",
        "threshold_ref",
    )

    for rid in sorted(set(old_by_id) | set(new_by_id)):
        if rid in old_by_id and rid not in new_by_id:
            r = old_by_id[rid]
            cls, reason = _classify_add_remove(r, added=False)
            rules_removed.append(
                RuleAddRemove(
                    rule_id=rid,
                    kind="removed",
                    rule_repr=_rule_repr(r),
                    change_class=cls,
                    reason=reason,
                )
            )
            continue
        if rid in new_by_id and rid not in old_by_id:
            r = new_by_id[rid]
            cls, reason = _classify_add_remove(r, added=True)
            rules_added.append(
                RuleAddRemove(
                    rule_id=rid,
                    kind="added",
                    rule_repr=_rule_repr(r),
                    change_class=cls,
                    reason=reason,
                )
            )
            continue

        old_r = old_by_id[rid]
        new_r = new_by_id[rid]
        for field in FIELDS:
            o = _get_field(old_r, field)
            n = _get_field(new_r, field)
            if _same(o, n):
                continue
            cls, reason = classify_rule_change(old_r, new_r, field, o, n)
            if cls is ChangeClass.NEUTRAL:
                ignored_count += 1
                continue
            changes.append(
                RuleChange(
                    rule_id=rid,
                    field=field,
                    old_repr=_repr(o),
                    new_repr=_repr(n),
                    change_class=cls,
                    reason=reason,
                )
            )

    return PolicyDiff(
        old_content_hash=old.metadata.get("content_hash", "")
        if isinstance(old.metadata, dict)
        else "",
        new_content_hash=new.metadata.get("content_hash", "")
        if isinstance(new.metadata, dict)
        else "",
        old_policy_version=old.policy_version,
        new_policy_version=new.policy_version,
        changes=tuple(changes),
        rules_added=tuple(rules_added),
        rules_removed=tuple(rules_removed),
        ignored_count=ignored_count,
    )


def _classify_add_remove(rule: Rule, *, added: bool) -> tuple[ChangeClass, str]:
    """A rule added or removed. Classification per SPEC-P1.3-CONFIG-DIFF §3."""
    if rule.mode is RuleMode.MONITOR:
        return (
            ChangeClass.NEUTRAL,
            "monitor rule does not bind the verdict",
        )
    if rule.action in (RuleAction.DENY, RuleAction.KILL):
        if added:
            return (
                ChangeClass.TIGHTENS,
                f"new {rule.action.value} rule binds the verdict",
            )
        return (
            ChangeClass.LOOSENS,
            f"{rule.action.value} rule removed; fewer rules can block",
        )
    if rule.action is RuleAction.MODIFY:
        return (
            ChangeClass.UNDECIDABLE,
            "a MODIFY rule may substitute for a DENY or an ALLOW; the "
            "direction depends on facts",
        )
    if rule.action is RuleAction.ALLOW:
        if rule.exempts:
            if added:
                return (
                    ChangeClass.LOOSENS,
                    f"new ALLOW rule grants exemptions {sorted(rule.exempts)}",
                )
            return (
                ChangeClass.TIGHTENS,
                f"ALLOW rule removed; exemptions {sorted(rule.exempts)} are "
                f"withdrawn",
            )
        return (
            ChangeClass.NEUTRAL,
            "an ALLOW rule with no exemptions does not change the verdict",
        )
    return (
        ChangeClass.UNDECIDABLE,
        f"action {rule.action.value} not in the classification table",
    )


def _get_field(rule: Rule, field: str) -> object:
    """Read a dotted field from a Rule without invoking pydantic's getattr twice."""
    if "." in field:
        head, tail = field.split(".", 1)
        obj = getattr(rule, head, None)
        if obj is None:
            return None
        return getattr(obj, tail, None)
    return getattr(rule, field, None)


def _repr(value: object) -> str:
    if value is None:
        return "None"
    if isinstance(value, Decimal):
        return str(value.normalize())
    if isinstance(value, enum.Enum):
        return str(value.value)
    if isinstance(value, (list, tuple)):
        return "[" + ", ".join(_repr(v) for v in value) + "]"
    return str(value)


def _rule_repr(rule: Rule) -> str:
    return f"{rule.id}(action={rule.action.value}, mode={rule.mode.value}, " \
           f"comparison={rule.comparison.value}, scope={rule.scope.value})"


# =============================================================================
# 6. THE APPROVAL FUNCTION (v2)
# =============================================================================


def assert_change_authorised_v2(
    diff: PolicyDiff,
    approver_ids: tuple[str, ...],
    governance: Governance,
) -> None:
    """The two-person rule, extended to every change the diff detects.

    Distinct approver IDENTITIES, not distinct approvals: two signatures from one
    person are one person's judgement twice.

    An UNDECIDABLE change requires approval: a direction that cannot be
    established is a change whose risk to the control cannot be bounded.
    """
    distinct = {a.strip().lower() for a in approver_ids if a.strip()}
    loosening_changes = diff.loosening_changes()
    loosening_adds = diff.loosening_add_removes()
    total = len(loosening_changes) + len(loosening_adds)
    if total == 0:
        return
    if len(distinct) < governance.min_approvals_to_loosen:
        # Name each loosening individually so an auditor sees the full list.
        detail_lines: list[str] = []
        for c in loosening_changes:
            detail_lines.append(
                f"  {c.rule_id}.{c.field}: {c.old_repr} -> {c.new_repr} "
                f"[{c.change_class.value}: {c.reason}]"
            )
        for a in loosening_adds:
            detail_lines.append(
                f"  {a.rule_id} ({a.kind}) [{a.change_class.value}: {a.reason}]"
            )
        raise PolicyGovernanceError(
            f"{total} loosening change(s) with "
            f"{len(distinct)} distinct approver(s); "
            f"{governance.min_approvals_to_loosen} required. Tightening needs "
            f"none.\n" + "\n".join(detail_lines)
        )

def _mutate(rule_id: str, field: str, new_value: object) -> PD.PolicyDiff:
    """Build a new PolicyDocument by patching a field on one rule, then diff."""
    doc_dict = DOC.model_dump(mode="python")
    rules = list(doc_dict["rules"])
    for r in rules:
        if r["id"] == rule_id:
            if "." in field:
                head, tail = field.split(".", 1)
                r[head] = dict(r[head])
                r[head][tail] = new_value
            else:
                r[field] = new_value
            break
    else:
        raise AssertionError(f"rule {rule_id} not in document")
    doc_dict["rules"] = rules
    mutated = PolicyDocument.model_validate(doc_dict)
    return PD.diff_policies(DOC, mutated)

def t_no_module_calls_v1_authoriser_directly():
    """Only config/policy_diff.py may call assert_change_authorised directly.

    A direct call bypasses the field-by-field classification. tests/ is exempt
    because the v1 function is what one of the existing suites tests.
    """
    import ast

    violations: list[str] = []
    for path in (REPO_ROOT / "src").rglob("*.py"):
        if path.name in ("loader.py", "policy_diff.py"):
            continue
        try:
            tree = ast.parse(path.read_text(encoding="utf-8"))
        except SyntaxError:
            continue
        for node in ast.walk(tree):
            if isinstance(node, ast.Call) and isinstance(node.func, ast.Attribute):
                if node.func.attr == "assert_change_authorised":
                    violations.append(f"{path}:{node.lineno}")
    require(not violations, "\n".join(violations))

## CONTINUE: tests/constitutional_pins.py (not required — the pins live inline in `tests/verify_p13_config_diff.py`)

I stopped at a clean file boundary. The pins are inline in the test file deliberately: extracting them to a separate module would put the pin data outside the file whose name an auditor greps for, and the file is already the right size.

Three things I want to flag explicitly before you say "continue":

1. **The `LOSS-004` mutation is stated as "threshold → 20%" in the prompt, but `LOSS-004` is 10% today.** I read it as `0.100 → 0.200` — a loosening on an `lte` rule. If the intended mutation was `0.100 → 0.020`, that is a **tightening** and the test must assert `TIGHTENS`, and `diff.requires_approval()` would be `False`. I have flagged this as `[DEFAULT-D1]` and `Q-P1.3-D1`. The classifier is correct either way; the fixture reading is the only variable.

2. **The `EXEC-001` mutation is not a threshold change.** It adds `MARKET` to `allowed_values` (the non-emergency set). Today's `allowed_values_emergency` already contains `MARKET`. If you meant "`allowed_values_emergency` gains a non-`MARKET` value", the classification would still be `LOOSENS` under `[DEFAULT-D2]`. If you meant "`EXEC-001` action changes from `DENY` to `ALLOW`", that is a completely different mutation and would be `t_mutation_exec001_action_allow`. The prompt's phrase "allows MARKET" reads most naturally as the `allowed_values` change, and I have implemented that.

3. **The `governance` diff path is a hard refusal, not an approval.** A change to `min_approvals_to_loosen` cannot be approved by any number of signatures — otherwise two signatures could lower the requirement to one. This is `[DEFAULT-D18]` and it is the only way the control survives its own amendment path. If you intend governance changes to be approvable, that requires a separate constitutional amendment (and ADR-09 is the wrong vehicle; it authorises the Owner alone, which would then authorise the Owner alone to lower the two-person rule).
